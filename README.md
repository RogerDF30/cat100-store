# CAT 100 Centennial Store (demo)

Static demo storefront for the CAT 100 Year collection: home, collections, product pages, cart, checkout and confirmation.

Single self-contained `index.html` (images embedded). No payment is taken and no order is sent.

Product names, specs and INR prices: CAT 100 Year Core products and Executive Line sheets (Sept 2024). Images: CAT100 Mockup Drive folder.
